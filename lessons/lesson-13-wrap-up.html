Wrap-up

Talk + discussion

Goal: see how your view changed, and keep using your agent.

Since the start of class you’ve built an AI agent that reads and writes files on your laptop, watched it make mistakes, and locked down what it may touch.

Using your agent from now on

The agent is yours. It lives in a folder on your laptop, with a private copy on GitHub. Here is the routine.

  1. Open the project folder in VS Code (File › Open Recent, or File › Open Folder). Open Claude Code and check that the mode reads Manual.
  2. Start every new case with an empty conversation. Anything worth keeping is already in files.
    Prompt
    /clear
  3. Brief a case. Drag the opinion’s PDF into the cases/ folder in the Explorer, then give its path.
    Prompt
    /brief cases/[file name].pdf
    Or skip the PDF and give a citation; the workflow fetches the opinion from CourtListener.
    Prompt
    /brief [case name, citation]
  4. Read the checker’s report before you read the brief, then check anything surprising against the opinion yourself. Run the same case again any time: the new brief is saved next to the old one, never over it.
  5. Commit and push after each brief. Over a semester, your history becomes a case log: every brief, with a date. In the terminal:
    Terminal
    git add .
git status
git commit -m "Brief: [case name]"
git push
    Read the git status list before you commit. (The Sync Changes button in the Source Control panel pushes too.)

Watch out

Everything your agent reads is sent to the model provider’s servers. Keep client files and anything confidential out of cases/ unless you know your account’s data settings, and your school’s or employer’s policy, allow it.

Before you rely on an agent’s output

Five questions, every time. They’re the same habits you’d use to supervise a junior associate’s memo.

  • Did you read the plan before approving it?
  • Does every claim have a quote and a pinpoint, and did the checker pass it?
  • Did you read the diff, not just the summary?
  • Did you check surprising claims against the opinion?
  • Is there anything secret or personal in what you’re about to share?
