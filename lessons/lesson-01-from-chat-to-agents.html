What is a model?

Every AI product you use is built around a model: a program that reads text and predicts what comes next. The app around it adds instructions, memory, tools and a chat window.

Terms

Model (LLM)
A large language model: the trained program that predicts the next piece of text. ChatGPT and Claude are apps built around models.
Token
The unit a model reads and writes, roughly three-quarters of an English word. Context limits and prices are counted in tokens.
Parameters
The billions of numbers adjusted during training until the model predicts text well. Once training ends, they’re fixed.
Context window
Everything the model can see at once: instructions, the conversation so far, and every file an agent reads.
System prompt
Hidden instructions the app gives the model before your message. Agent files and CLAUDE.md work the same way.
Knowledge cutoff
The date where the training data stops. Anything newer reaches the model only through tools like search.
Sampling and temperature
The model picks among likely next tokens with some randomness, so the same prompt can give different answers. Temperature sets how much randomness.
Hallucination
Confident output that isn’t true, such as an invented case or a paper that doesn’t exist.

Why it matters

A model doesn’t look anything up unless the app gives it a tool. When it “remembers” a case name, it is predicting text that looks like a case name. That is why the agent you build today has to verify every source.

What happens when you press Enter

When you send a message, the app doesn’t send just your words. It assembles a context window, and the model writes its reply one token at a time. Each new token is added to the context before the next one is predicted.

Three consequences worth remembering:

  • Nothing you type changes the model. Corrections live in the context window, and disappear when the conversation does.
  • The context window fills up. Long conversations and big files push older material out or crowd it, which is why you’ll start each new topic with /clear.
  • Randomness is built in. Ask twice, get two answers. That’s fine for drafting and a problem for anything you’ll cite.
