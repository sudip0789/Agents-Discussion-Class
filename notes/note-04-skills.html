Concept note N4

Skills, and how to choose them

In one line: a skill is a folder of instructions an agent loads when it’s relevant; choose few, choose well, and read them before installing.

A skill is the agent version of a practice guide: written instructions for doing one kind of task well, which the agent pulls off the shelf when the task comes up. Because a skill is instructions the agent will follow, and sometimes code it will run, installing a stranger’s skill is closer to installing software than to bookmarking a web page.

What a skill is

A skill is a folder containing a file named SKILL.md, and sometimes scripts or reference files. SKILL.md is a Markdown file with a short header (the frontmatter, between two --- lines) followed by plain-language instructions.

PartWhat it’s for
SKILL.md (required)The frontmatter and the instructions themselves
scripts/ (optional)Programs the agent can run as part of the skill
references/ (optional)Longer documents the agent reads only if it needs them
assets/ (optional)Templates, images and other files the skill uses

The frontmatter

Here’s what each field in your own /brief skill does:

FieldWhat it does
nameThe skill’s name, and the command you type: name: brief becomes /brief
descriptionTells the agent when to use the skill. This is the line the agent always sees, so it does most of the work
argument-hintA Claude Code extra: the hint shown after /brief as you type; yours is [path to an opinion in cases/]
$ARGUMENTSNot a field but a placeholder in the instructions: replaced by whatever you type after the command, such as cases/marbury-v-madison.pdf

Other optional fields in Claude Code include disable-model-invocation (only you can run the skill; the agent can’t load it on its own) and allowed-tools (tools the skill may use without asking). The second one deserves a close look in any skill you didn’t write.

Where skills live

A pluginWherever you install it. Plugins bundle skills (and sometimes agents and other settings) for sharing

An open standard

Agent Skills is an open standard, originally developed by Anthropic and published at agentskills.io. The same SKILL.md format works in Claude Code, OpenAI’s Codex, Gemini CLI, GitHub Copilot, VS Code, Cursor and other tools. A skill you write for one agent will mostly work in the others, though some fields, like argument-hint, are extras particular to one tool.

What loads when: progressive disclosure

If every skill’s full instructions sat in the context window all the time, a dozen skills would crowd out your actual work. Skills avoid that with a design Anthropic calls progressive disclosure: the agent sees a little about every skill, and reads more only when it needs to.

Why it matters

Level 1 is paid in every session, for every skill you install, whether you use it or not. Twenty skills means twenty descriptions in the context window before you’ve typed anything, and twenty chances for the agent to load the wrong one. Fewer, well-described skills work better.

Skill vs subagent vs CLAUDE.md

All three are Markdown files of instructions, which makes them easy to confuse. The difference is when they load and whose context they live in.

SkillSubagentCLAUDE.md
What it isA folder of instructions, sometimes with scriptsA separate agent with its own instructions and toolsA file of standing instructions
When it loadsDescription always; full instructions when relevant, or when you type /nameWhen the main agent hands it a taskAt the start of every session
Whose contextAdds to the current conversationIts own fresh context windowEvery conversation, including subagents’
ToolsUses the current agent’s toolsOnly those on its tools: lineNone; it’s just text
Best forA repeatable procedureAn independent job, like checking someone else’s workRules that always apply
Lives in.claude/skills/.claude/agents/The project folder
In your project/briefcase-briefer, brief-checkerCLAUDE.md

A useful test: if it’s a procedure (“when asked to do X, do these steps”), make it a skill. If it’s a job for someone else, especially one that needs different powers, make it a subagent. If it’s a rule that should never be off, put it in CLAUDE.md.

Licenses differ even within one repository. Most of Anthropic’s example skills are open source (Apache 2.0), but its document skills (Word, PDF, PowerPoint, Excel) are source-available: you can read the code, but the license limits copying and reuse. Check the license file before adapting someone else’s skill.

How to choose a skill

  1. Start from a task you repeat, not from a list of popular skills. If you can’t name the task, you don’t need the skill.
  2. Prefer known publishers and repositories that are actively maintained: recent updates, open issues that get answers, a clear license.
  3. Read the SKILL.md and any scripts before installing. It’s Markdown; you can read it in a few minutes. If there are scripts you can’t follow, that is itself a warning sign.
  4. Scan it with SkillSpector, NVIDIA’s free, open-source scanner for agent skills. It gives a risk score from 0 to 100 and a recommendation:
    ScoreRiskRecommendation
    0–20LowSafe
    21–50MediumCaution
    51–80HighDo Not Install
    81–100CriticalDo Not Install

    Source: SkillSpector README, NVIDIA.

  5. Be extra careful with skills that include scripts. A 2026 academic study of about 31,000 public skills (Liu et al., “Agent Skills in the Wild”) found that skills bundling executable scripts were about 2.12 times more likely to contain a vulnerability than instruction-only skills (source).
  6. Install one at a time, in one project, and test it on a real task before relying on it.
  7. Remove skills you don’t use. Every installed skill’s description takes up room in the context window, in every session.

Watch out

The score helps you decide. It doesn’t replace reading the skill. A scanner looks for known patterns; a skill can be harmful in ways no pattern catches, and a low score is not a guarantee.

Red flags

Stop and think twice if a skill has any of these:

  • Instructions to read secrets: .env files, passwords, API keys, SSH keys, browser data
  • Sending data to websites or servers you don’t recognize
  • Hidden or encoded text: long strings of random-looking characters, or text formatted to be invisible
  • Instructions to ignore other rules, skip approvals or change permission settings
  • An allowed-tools line that grants more than the task needs, especially Bash
  • A vague description (“use for everything”), which makes it load when it shouldn’t
  • Scripts or code you can’t follow
What the research on public skills found

In January 2026, researchers from several universities and a security firm published the first large-scale study of public agent skills. They collected 42,447 skills and analyzed 31,132 of them for security problems.

FindingFigure
Skills with at least one vulnerability26.1%
Skills with high-severity patterns suggesting malicious intent5.2%
Higher likelihood of a vulnerability when a skill bundles executable scripts2.12× (odds ratio)

Source: Yi Liu et al., “Agent Skills in the Wild: An Empirical Study of Security Vulnerabilities at Scale,” arXiv:2601.10338 (Jan. 15, 2026).

Two cautions when you repeat these numbers:

  • Who did the study. These figures come from the academic paper, not from NVIDIA. NVIDIA’s SkillSpector README cites the paper; some blog posts describe the numbers as “NVIDIA’s research,” which is wrong.
  • What “malicious” means here. The 5.2% are skills showing high-severity patterns that suggest malicious intent, not confirmed malware. Treat the figure as a reason to read carefully, not as a count of attacks.

Anthropic’s own advice points the same way: install skills only from trusted sources, and for anything less trusted, audit the skill first, starting with its bundled files and any instructions that reach out to the network.

Installing a skill library in Claude Code

Libraries like Superpowers and Anthropic’s skills are distributed as plugins. You type these commands into the Claude Code prompt box, not the terminal. Read the repository first, as the checklist above says.

Superpowers:

Prompt
/plugin install superpowers@claude-plugins-official

Anthropic’s skills (add the marketplace, then install the document skills):

Prompt
/plugin marketplace add anthropics/skills
Prompt
/plugin install document-skills@anthropic-agent-skills

SkillSpector is a separate command-line program. It installs with uv, a Python tool installer; the README explains how to point it at a skill folder:

Terminal
uv tool install git+https://github.com/NVIDIA/skillspector.git
